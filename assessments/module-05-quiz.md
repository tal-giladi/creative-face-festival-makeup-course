# Module 5 quiz

This quiz checks the decisions behind a festival face: choosing bold colors that read from a
distance on any skin tone, preparing and setting the skin so the design lasts all day, placing a
symmetrical layout that lifts the face, and keeping bold eye designs safe. Every question is a short
real-life situation. You need 70% to pass, and you can retake it.
