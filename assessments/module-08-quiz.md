# Module 8 quiz

This quiz checks the decisions behind advanced color and illusion: choosing colors for a clean
three-color blend, loading and caring for a split cake, placing highlights and shadows so shapes look
3D, using stencils cleanly and safely, painting scales and lace, and making an illusion read as a hole
or a bump on the face. Every question is a short real-life situation. You need 70% to pass, and you
can retake it.
